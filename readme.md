# exam-app - 系统集成项目管理工程师备考系统

## 📖 项目简介

这是一个专为系统集成项目管理工程师考试设计的备考系统，包含学习计划、学习重点、学习笔记、真题练习、冲刺复习、模拟考试等完整功能。

## 🎯 功能特性

### 1. 📅 学习计划
- 自动生成8周学习计划
- 进度跟踪与可视化
- 每日任务管理

### 2. 📚 学习重点
- 17章完整知识点
- 重要程度标注
- 核心公式速查

### 3. 📝 学习笔记
- 自由创建笔记
- 自动保存功能
- 分类管理

### 4. ✍️ 真题练习
- 历年真题（2007-2026，含案例题）
- 分类筛选（年份/题型/章节）
- 练习统计

### 5. ⚡ 选择冲刺 / 📝 高频默写 / 📌 考前必背 / 🧮 案例冲刺
- 按章节刷选择题（6 套冲刺卷）
- 关键词填空自测（13 组默写 + 33 条记忆表）
- 高频考点速记（考前必背）
- 案例分析答题框架（5 大计算模板）

### 6. 📖 教材习题
- 第三版教材课后习题（18 章）
- 单选/多选/案例分栏练习

### 7. 🔤 专业英语
- 命题趋势分析（7 大趋势）
- 275 个高频词汇（8 大分类，支持默记/标记）
- 62 道历年英语真题 + 中文解析

### 8. 📊 模拟考试 / 💻 机考模拟
- 上午/下午全真计时
- 成绩分析与薄弱环节识别
- 3 套机考卷（75 题/套）+ 4 道案例大题
- 按机考界面还原的作答流程

### 9. ❌ 错题本 / 📋 案例模板
- 自动记录错题、详细解析、针对性复习
- 7 类案例分析模板 + 挣值等计算模板

### 10. 💎 会员中心
- 免费版 / 全站年卡 / 永久买断三档方案
- 7 天免费试用（每设备仅一次）
- 离线激活码解锁（SHA-256 校验，不联网、不上传数据）
- 会员专属：模拟考试、机考模拟、选择冲刺、高频默写、考前必背、案例冲刺、教材习题、专业英语真题

## 🚀 快速开始

### 方式一：直接打开（推荐）

1. 找到项目文件夹
2. 双击 `index.html` 文件
3. 在浏览器中自动打开应用

### 方式二：使用本地服务器

```bash
# 进入项目目录
cd exam-prep-app

# 使用Python启动服务器
python -m http.server 8080

# 或使用Node.js
npx http-server

# 打开浏览器访问
# http://localhost:8080
```

## 📂 项目结构

```
examapp/
├── index.html                 # 主页面（单页应用模板）
├── styles.css                 # 样式文件
├── app.js                     # Vue 实例：全部状态与业务逻辑
├── db.js                      # IndexedDB 封装（笔记/错题/考试记录/进度）
├── vue.min.js                 # Vue 2.6 本地运行时（离线可用）
├── questions.js               # 历年真题题库
├── chapters.js                # 17 章知识点
├── sprint_questions.js        # 选择题冲刺卷
├── dictation_data.js          # 高频默写数据
├── must_memorize_data.js      # 考前必背数据
├── case_sprint_data.js        # 案例冲刺数据
├── textbook_exercises_data.js # 教材课后习题
├── handbook_data.js           # 考点冲刺手册
├── case_templates.js          # 案例分析模板
├── english_data.js            # 专业英语（趋势/词汇/真题）
├── mock_exam_a|b|c.js         # 3 套机考模拟卷
├── mindmap.js                 # 思维导图下载
├── docs/                      # 内部规范与调研文档
└── .github/workflows/pages.yml# GitHub Pages 自动部署
```

> 数据文件通过 `window.xxx` 全局挂载，`index.html` 底部按顺序引入；修改数据后请同步更新 `<script src="...?v=N">` 的版本号以刷新浏览器缓存。

## 💾 数据存储

应用使用 **IndexedDB** 进行本地数据存储，所有数据保存在浏览器中：
- 学习进度
- 学习笔记
- 考试记录
- 错题本
- 练习统计

**注意**：清除浏览器数据会导致学习记录丢失，请注意备份。

## 📝 使用说明

### 学习计划

1. 点击左侧菜单"学习计划"
2. 查看自动生成的8周计划
3. 勾选已完成的任务
4. 系统自动计算进度

### 模拟考试

1. 点击左侧菜单"模拟考试"
2. 选择"上午考试"或"下午考试"
3. 开始答题（注意计时）
4. 提交后查看成绩和分析

### 冲刺复习

1. 点击"冲刺复习"
2. 使用翻转卡片记忆知识点
3. 点击卡片翻转查看答案
4. 标记"认识"或"不认识"

### 错题本

- 做错的题目自动进入错题本
- 可以查看详细解析
- 支持重新练习和移除

## 🔧 自定义扩展

### 添加新题目

编辑 `src/data/questions.js` 文件，按以下格式添加：

```javascript
{
    id: 'q2025001',
    year: 2025,
    type: 'morning',  // morning 或 afternoon
    chapter: 'project_integration',
    chapterName: '项目整体管理',
    title: '题目内容',
    question: '完整题目描述',
    options: [
        { label: 'A', text: '选项A' },
        { label: 'B', text: '选项B' },
        { label: 'C', text: '选项C' },
        { label: 'D', text: '选项D' }
    ],
    answer: 'C',
    explanation: '详细解析',
    tags: ['标签1', '标签2'],
    difficulty: 'medium'  // low, medium, high
}
```

### 添加新章节

编辑 `src/data/chapters.js` 文件。

### 添加新公式

编辑 `src/data/formulas.js` 文件。
